# Mockups

Telas do produto, organizadas pelas cinco fases da dor da persona:

1. **A suspeita** — boletim diário de risco
2. **A confirmação** — relato pelo bot de WhatsApp
3. **A corrida** — alerta com cone de propagação e ligação de voz
4. **O combate** — mapa de recursos (pipa, açude, trator, brigada)
5. **O depois** — laudo georreferenciado com carimbo do tempo
